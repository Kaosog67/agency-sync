Какие данные мы получаем

С разрешения пользователя приложение читает статистику поиска из Google Search Console (область доступа webmasters.readonly): клики, показы, CTR, позиции, запросы, страницы, устройства и страны по сайтам, к которым у пользователя есть доступ. Приложение не читает почту, контакты, файлы и другие данные Google-аккаунта.

Как используем

Данные записываются в Google-таблицу, принадлежащую пользователю, и используются только для отчётов о работе его сайтов.

Хранение и передача

Данные хранятся в Google-таблице пользователя. Мы не продаём данные, не передаём их третьим лицам и не используем для рекламы. Использование информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа и удаление

Отозвать доступ можно в любой момент на странице myaccount.google.com/permissions. Чтобы удалить выгруженные данные, удалите Google-таблицу или напишите нам.
